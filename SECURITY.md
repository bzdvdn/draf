name: Security Policy

## Reporting a vulnerability

Teff is a small project without a dedicated security channel. Please report a
suspected vulnerability **privately first**:

- If the repository has GitHub Private Vulnerability Reporting enabled, use
  **Security → Report a vulnerability** in the repository.
- Otherwise, open a GitHub issue with the `security` label, or — for
  something sensitive — reach the maintainer privately before any public
  disclosure.

## What we ask

- Do **not** open a public issue describing an exploitable bug before it's
  fixed.
- Include a minimal repro: the `teff` version, the workflow/snippet, and the
  impact you observed.
- Give us a reasonable window (preferably 7+ days) to respond before
  disclosure.

## Supported versions

Security fixes are released on the latest `main` and, where feasible, backported
to the latest tagged release. Check the [CHANGELOG](CHANGELOG.md) for release
notes.
